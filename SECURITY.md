# Security policy

This package handles payment callbacks, so security reports are taken seriously.

**Please do not open a public issue for a vulnerability.** Report it privately through
[GitHub security advisories](https://github.com/MBotirjonDev/uz_payments/security/advisories/new)
or on Telegram to [@MBotirjon03](https://t.me/MBotirjon03). You will get a reply within 72 hours.

Only the latest release receives fixes.
